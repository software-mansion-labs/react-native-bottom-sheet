# React Native Bottom Sheet

<Lead>
  Bottom-sheet components for React Native. Gestures, snapping, and scroll
  coordination run in native code, and everything you see is plain React Native,
  on iOS, Android, and the web.
</Lead>

```sh
npm i @swmansion/react-native-bottom-sheet
```

<StartHere />

## Highlights

<Highlights>

- Native implementation on iOS and Android for optimal performance.
- Web support through React Native Web.
- Both inline and modal sheet components.
- Bring your own sheet surface.
- Floating card sheets with per-detent insets.
- Dynamic, content-based sizing out of the box.
- Automatic handling of vertically scrollable children.
- Position tracking for driving UI tied to sheets.
- Programmatic-only detents for snap points unreachable by dragging.

</Highlights>
