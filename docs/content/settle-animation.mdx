# Settle animation

When a drag ends or the index changes, a spring carries the sheet to its detent.
`settleDuration` is how long, in seconds, that spring takes. Left unset, it
takes 0.45 seconds on every platform.

```tsx
<BottomSheet
  detents={[0, 'content']}
  index={index}
  onIndexChange={setIndex}
  settleDuration={0.55}
  surface={/* ... */}
>
  {/* ... */}
</BottomSheet>
```

The spring is critically damped, so the duration is also its stiffness: a longer
duration is a softer settle.

Release velocity is carried into the spring at any duration, so a fast release
still starts fast. Above about 1.6 seconds, a fast release can briefly carry the
sheet past the detent before it returns, because the release velocity outlasts
the softer spring.
